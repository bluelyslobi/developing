# 트래블시커 세션 정리
날짜: 2026-07-03

---

## 오늘 결정한 것들

### 1. 앱 방향 확정
- 핵심 기능: 해외여행자 커뮤니티
- 커뮤니티가 먼저 커지면 → 중고거래 → 패키지로 자연스럽게 연결
- 차별점: 외화 직거래 매칭 (수수료 없이 유저끼리 직접 교환, 은행보다 싸게)
- 외화 직거래 기능을 트래블시커에 직접 구현 후 배포 결정

### 2. 수익 로드맵
- 1단계: 유저 모으기 (무료 — 커뮤니티 + 외화 직거래 매칭)
- 2단계: 중고거래 수수료 + 패키지 중개 수수료
- 3단계: 배너 광고 (여행사, 환전소, 여행용품 브랜드)

### 3. 마케팅 전략 (제로 예산)
- 지인 → 기존 커뮤니티 침투 → 콘텐츠 유입 순서
- 메인 채널: 네이버 블로그 (bestbik, 누적 방문자 36만 활용)
- 보조 채널: 인스타그램
- 블로그 실행 순서:
  1주차: 기존 여행 글 업데이트 (블로그 재활성화)
  2주차: "코딩 몰랐던 내가 여행 앱 만든 이야기" 발행
  3주차~: 환전 특화 시리즈 (외화 직거래 연결)
