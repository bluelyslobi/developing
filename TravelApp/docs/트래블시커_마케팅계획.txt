# 트래블시커 마케팅 계획
작성일: 2026-07-03

---

## 앱 컨셉 방향

- 핵심: 해외여행자 커뮤니티 (커뮤니티가 먼저, 나머지는 따라오는 구조)
- 차별점: 외화 직거래 매칭 (수수료 없이 유저끼리 직접 교환)
- 확장 순서: 커뮤니티 → 중고거래 → 패키지 → 광고

---

## 수익 로드맵

1단계 — 유저 모으기 (무료 제공)
  - 여행 정보 커뮤니티
  - 외화 직거래 매칭 (수수료 없음, 은행보다 싸게)

2단계 — 수수료 수익
  - 해외여행 물품 중고거래 수수료
  - 패키지 상품 중개 수수료

3단계 — 광고 수익 (유저가 쌓이면)
  - 여행사, 환전소, 여행용품 브랜드 배너 광고

---

## 초기 유저 확보 전략 (제로 예산)

### 1단계 — 지인 (목표: 10~20명)
- 카카오톡 지인들에게 직접 링크 공유
- "써봐"가 아니라 "솔직한 피드백 줘" 로 접근

### 2단계 — 기존 커뮤니티 침투 (목표: 50명)
- 네이버 카페: 세계여행, 유랑, 일본여행 카페 등
- 에브리타임: 대학생 해외여행 수요
- 블라인드: 직장인 여행 준비 글
- 카카오 오픈채팅: 여행 준비방 자연스럽게 참여
- 방법: 광고 글 X, 진짜 유용한 정보 제공자로 신뢰 먼저 쌓기

### 3단계 — 콘텐츠 유입 (목표: 100명+)
- 네이버 블로그 메인, 인스타 보조
- 블로그 누적 방문자 36만 자산 활용

---

## 블로그 마케팅 실행 계획

보유 자산:
- 네이버 블로그 (bestbik): 누적 방문자 36만, 여행 글 약 50개
- 현재 휴면 상태 → 재활성화 필요

### 1주차 — 블로그 워밍업
- 기존 여행 글 3~5개 하단에 "2026 업데이트" 추가
- 트래블시커 언급 없이 일단 블로그 활성화부터

### 2주차 — 앱 출시 스토리
- "코딩 몰랐던 내가 여행 앱 만든 이야기" 글 발행
- 바이럴 가능성 높음 (공감대 + 궁금증 유발)

### 3주차부터 — 환전 특화 시리즈
- "일본 환전 은행 vs 직거래 실제 비교"
- "태국 바트 환전 손해 안 보는 방법"
- 글 말미에 트래블시커 외화 직거래 기능 자연스럽게 연결
- 검색 유입 + 트래블시커 직접 연결 되는 가장 강력한 콘텐츠

---

## 채널 전략
- 메인: 네이버 블로그 (검색 유입, 장기 자산)
- 보조: 인스타그램 (숏폼 릴스, 여행 실용 정보)
- 100명 돌파 후: 트래블시커 전용 인스타 채널 개설 고려

## 현재 앱 상태 (배포 전 해결 과제)
- 외화 직거래 매칭 기능 미구현 → 컨셉 재정비 필요
- 커뮤니티 / 중고거래 / 패키지 기능은 완성
- 배포 전 외화 직거래 기능 방향 확정 필요
