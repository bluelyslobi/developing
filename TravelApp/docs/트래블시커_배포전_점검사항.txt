트래블시커 배포 전 점검 결과 (2026-08-06 최초 작성 / 2026-08-06 업데이트)
=======================================================

■ 남은 것 — 사람이 직접 해야 하는 작업 (2건)

1. Firebase Storage 콘솔 설정 [미해결]
   - https://console.firebase.google.com/project/travelshare-b6659/storage
     에서 "시작하기" 클릭 (위치는 서울/asia-northeast3 권장).
   - 이거 안 하면 커뮤니티/중고거래/패키지 사진 업로드가 전부 실패함.
   - 완료 후 다음 명령으로 storage.rules 배포:
       cd TravelApp
       npx firebase-tools deploy --only storage

2. EAS 프로젝트 초기화 [미해결]
   - App.js는 이제 app.json의 extra.eas.projectId를 동적으로 읽도록 수정 완료.
     아래 명령만 실행하면 코드 수정 없이 자동으로 정상화됨.
       cd TravelApp
       npx eas-cli login    (Expo 계정 로그인 필요 — 직접 실행)
       npx eas-cli init     (app.json의 projectId를 실제 값으로 자동 교체)

3. eas.json iOS 제출 설정 [애플 개발자 계정 등록 후 진행]
   - Apple ID / App Store Connect App ID / Team ID가 있어야 채울 수 있음.
   - 애플 개발자 계정($99/년) 등록 후 `eas submit --platform ios` 실행하면
     CLI가 대화형으로 물어보고 알아서 eas.json에 저장해줌.
